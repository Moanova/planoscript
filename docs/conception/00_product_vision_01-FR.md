# Planoscript :: Vision produit


## Planoscript : Un éditeur visuel de carte narrative pour les créateurs de récits complexes.
- **Description**:
    Planoscript est l’outil qui permet aux scénaristes de jeux vidéo, de micro-séries ou d’autres formes de fiction moderne de
      - construire visuellement leurs cartes narratives par glisser-déposer sans compétences techniques,
      - gérer les embranchements et les arcs narratifs avec une vue claire des liens entre éléments,
      - exporter leurs travaux dans des formats universels pour collaborer avec leurs équipes (développeurs, réalisateurs) sans opérations manuelles.
    Pourquoi ?
    Les éditeurs de traitement de texte classiques sont inadaptés et les applications professionnelles spécifiques sont soit trop complexes, soit trop coûteuses.
    Aucune solution ne répond exactement aux besoins des créateurs de fictions modernes, notamment indépendants.
    1. Flexibilité : adapté aux récits complexes et non linéaires.
    2. Simplicité : interface intuitive zéro code pour se concentrer sur la structuration des récits.
    3. Collaboration : partage simplifié avec les équipes via des exports directement exploitables.
    En une phrase, Planoscript est le couteau suisse visuel des scénaristes indépendants pour structurer des récits complexes sans se perdre dans la technique.
